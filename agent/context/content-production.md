# Producción de contenido — índice

Pipeline oficial cuando Phil pide IG, LinkedIn, Facebook, stories o video.

**Skill principal:** [`../skills/content_production/SKILL.md`](../skills/content_production/SKILL.md)

## Resumen en 7 pasos

1. **Investigar** — tendencias del tema (web, noticias tech/software)
2. **Filtrar Wavys** — solo ángulos ligados a IA, WhatsApp, leads, automatización
3. **Elegir formato** — story 15s, post, carrusel, LinkedIn…
4. **Copy + guion** — creativo, distinto cada vez
5. **Visual** — Figma Agente + Gemini + Remotion/remocn (video)
6. **Generar** — tools + render
7. **Entregar** — paquete a Phil; **no publicar** sin OK

## Ejemplo: Story Mundial 15s

- Investigar: IA/apps/picos de mensajes en eventos masivos
- Puente Wavys: “mientras hay pico, agentes responden 24/7 en WhatsApp”
- Formato: 1080×1920, 15s, Remotion + remocn
- Ver skill para guion por segundos y entregables
